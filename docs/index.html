The problem it solves

Released music has too much infrastructure. Unreleased music has almost none. Folders don’t help you find the good bounce. Upload tools don’t understand tags. Streaming apps assume the song is finished.

So the work is technically stored and practically missing. cr8 is software for the middle: demos, versions, judgment while the music is on.

What you get

  • Library — dig, filter, shuffle a real archive
  • Tag while it plays — status, key, vibe, keepers, collabs
  • Send a link — friends listen without hunting a folder
  • Invite a circle — members, presence, shared listening
  • Stems when you need them — local separation, optional tools

The original files stay read-only. Opinions live in a catalog. Streams come from a disposable mirror you can rebuild.

Not a business

This is a project. Most personal circles don’t need a stadium product. They need something fast, reliable, and theirs — that friends can run too.
