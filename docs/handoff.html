What cr8 is (30 seconds)

Self-hosted listening software for original / unreleased music. Dig the archive, tag while it plays, send links to a circle, optional stems. The music folder is read-only; opinions live in SQLite; streams come from a disposable mirror.

Not a SaaS. Not our production catalog. You run your own crate.

Requirements

  • Python 3.12+ (3.14 is fine)
  • Node.js + pnpm
  • ffmpeg + ffprobe on PATH (hard requirement for media work)
  • macOS or Linux preferred; Windows may work with extra path care

Optional later: keyfinder-cli / aubio for enrichment. Missing tools are skipped cleanly.

Human path — local setup

git clone https://github.com/hareeshnagaraj/cr8.git
cd cr8

python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -e '.[dev]'

cr8 init
# when prompted: corpus root = any folder of audio you own
# (or a temporary empty tree just to boot the UI)

cd web && pnpm install && cd ..

# terminal 1 — API
./.venv/bin/uvicorn cr8.web.owner.app:create_app --factory \
  --host 127.0.0.1 --port 8080

# terminal 2 — web
cd web && pnpm dev
# → http://127.0.0.1:3100

Then open http://127.0.0.1:3100/setup and create the first user. That is your owner account.

If you pointed init at real music:

cr8 scan
# when you want streamable mirrors:
# cr8 build

Empty or tiny corpora still prove the app boots. Full dig/tag value needs real files.

What “works” means

  • /setup creates a user and lands you in the app
  • Login survives refresh
  • Library page loads (even with 0 tracks)
  • After cr8 scan (+ build if needed), a track can play from the dock
  • You never needed production SSH, secrets, or ops/env

How we collaborate on code

  • Repo is public — anyone can read and open PRs
  • Merges are restricted — only collaborators (invited people) can merge to main
  • Prefer feature branches + pull requests
  • Do not commit secrets, ops/env, passwords, or personal hostnames
  • Operator deploy docs live under ops/ for people who self-host later — skip for pure local dev

GitHub access

Collaborators get a GitHub invite for write access. Accept it, then push branches to the main repo (or fork + PR — either is fine). If you only need to run the app, a plain clone is enough.

Agent handoff (paste into your LLM)

If you have a coding agent with shell access, paste the following block as the task. It is intentionally self-contained and local-only.

TASK: Boot cr8 fully local and verify You are helping a developer set up https://github.com/hareeshnagaraj/cr8 on THEIR machine. Goals (in order): 1. Clone the public repo (or use existing checkout). 2. Create venv, pip install -e '.[dev]'. 3. Run `cr8 init` non-interactively if possible, or with a temp corpus directory if the user has no music path yet. 4. Install web deps (pnpm in web/). 5. Start API on 127.0.0.1:8080 and Next on 127.0.0.1:3100. 6. Verify: GET /healthz or /login on :8080, open :3100/setup or /login, confirm app shell loads. 7. Optionally run `cr8 scan` if a corpus exists; do not invent production deploy steps. Hard constraints: - DO NOT request or use production secrets, ops/env, SSH hosts, or cr8.li credentials. - DO NOT write into any music corpus outside the configured root; the system is read-only to the archive. - DO NOT commit secrets, config.toml with personal paths if the user forbids, or ops/env. - Prefer fully local. Skip Cloudflare, deploy.sh, and launchd unless the user explicitly asks to self-host publicly. - If ffmpeg/ffprobe missing, install via brew/apt or stop with a clear message. - If ports 8080/3100 busy, free them or choose alternates and document. Acceptance: - pytest can wait; first bar is boot + /setup path. - Report exact commands run, URLs, and any blockers. Context: - Product: self-hosted crate for unreleased music (FastAPI + SQLite + Next.js). - Public story: https://hareeshnagaraj.github.io/cr8/ - Architecture brief: https://hareeshnagaraj.github.io/cr8/architecture.html

Built as a passion project so friends can share original music without a SaaS in the middle. Open source so everyone can run a crate.
